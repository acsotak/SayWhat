## Project name
SayWhat?

## Purpose
A comprehension barrier diagnostic tool that helps users understand confusing expressions by examining context and aiming to determine the source of confusion while providing a contextually-aware explanation of the phrase. 

## Name
Amanda Sotak

## Technologies used
- HTML
- CSS
- JavaScript

## Prerequisites
- Web browser
- Git (for cloning)
- No additional dependencies

## Installation
- Clone the repository:
`git clone https://github.com/acsotak/SayWhat`
- If using terminal, navigate to the project directory
`cd SayWhat`
- Open index.html in web browser

## Configuration
No configuration is required

## Running the Application
- Open `SayWhat` project folder
- Double click `index.html` to launch application in browser
- SayWhat? Homepage will appear

## Trying Sprint 1 Functionality
- Enter `bless your heart` into the text box
- Click submit arrow or press Enter
- Wait for Results page to load
- View the phrase explanation
- Press `X` in upper right corner to return to the homepage
- Enter any other phrase or word and press Enter/submit arrow
- Once Results page loads, verify a "no match found" style message appears

## Known Limitations
- Phrase recognition logic was intentionally limited in Sprint 1. As a result, the logic is hardcoded in JavaScript
- Only one phrase is stored as recognized ("bless your heart")
- Input is spelling sensitive
- Save/Suggest buttons are non-functional
